Trạm Cân QR 0.2.0-rc50

### Cập nhật chính
- Thêm cột **Đẩy kho** trên danh sách lần cân: **Chờ đẩy kho** / **Đã đẩy kho**.
- Cuộn đã đẩy không được chọn lại ở lần đẩy kho sau.
- Tổng hợp đẩy kho có nút **In PDF** (hộp thoại in → Microsoft Print to PDF / Save as PDF).
- Giữ lưu CSV/JSON tổng hợp vào thư mục exports trên máy.

### Cài đặt
Đóng ứng dụng, cài đè bản mới. Dữ liệu và `config.env` được giữ nguyên.
